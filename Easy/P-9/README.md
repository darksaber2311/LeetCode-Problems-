# Problem 9: Palindrome Number

## Method
Number Reversal

## Solution Logic
Reverse the number by extracting digits from right to left and building the reversed number. Compare the reversed number with the original number. If they are equal, the number is a palindrome.

## Complexity
- **Time Complexity:** O(log₁₀ n) - Number of digits in the number
- **Space Complexity:** O(1) - Constant extra space
